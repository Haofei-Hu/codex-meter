Mac 界面更新为液态玻璃风格。

- macOS 26+ 使用系统原生 Liquid Glass；macOS 13–15 使用背景模糊的毛玻璃兼容材质。
- 桌面卡片、状态栏展开面板和设置面板统一半透明表面、柔和高光与细边框，工作进度采用更轻的内层面板。
- 设置和刷新按钮加入玻璃高光，保留额度渐变色、双额度布局与四周边缘拖动、右下角缩放。
- 开启系统“降低透明度”后使用实色背景，保持文字可读性。玻璃装饰层不接收鼠标事件。

推荐安装 `CodexMeter-1.5.1.6-universal.pkg` 自动替换旧版，保留设置和登录。支持 macOS 13+、Apple 芯片与 Intel；DMG / ZIP 为手动替换方式。安装包尚未正式签名或公证，附 SHA-256 校验文件。

Windows 继续使用 [1.5.2](https://github.com/Haofei-Hu/codex-meter/releases/tag/v1.5.2)，Linux 继续使用 [1.5.1](https://github.com/Haofei-Hu/codex-meter/releases/tag/v1.5.1)。MIT · Independent project, not affiliated with OpenAI.
