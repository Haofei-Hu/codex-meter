### 推荐下载 PKG，自动替换旧版

下载 `CodexMeter-1.5.1.1-universal.pkg` 并按系统安装向导操作。支持 macOS 13+、Apple 芯片和 Intel。

安装器会停止旧程序，将新版安装到 `/Applications/Codex Meter.app` 并覆盖该位置的旧版；安装成功后，把 `/Applications` 与当前用户 `~/Applications` 中具有相同应用标识的其他旧副本移入废纸篓。保留登录、偏好与任务记录，不清空废纸篓，不删除其他应用或更高版本。安装失败时保留其他旧副本。

安装完成后从“应用程序”启动 Codex Meter。无需手动卸载或重新登录 Codex。

DMG / ZIP 供手动安装，**不执行自动清理**。所有下载均附 SHA-256 校验值。应用及安装包尚未正式签名/公证，首次打开可能出现系统提示；请从本仓库下载。

Windows / Linux 没有新的程序改动，继续使用 [1.5.1 下载页](https://github.com/Haofei-Hu/codex-meter/releases/tag/v1.5.1)。
