新增 Mac 玻璃外观调整。

- 在卡片设置和状态栏展开面板中加入“玻璃外观”：分别选择桌面卡片或弹出面板，调节透明度与磨砂强度。
- 拖动时实时预览，设置在重启后保留；支持同步到另一种面板，以及单独还原系统默认。
- 只调整背景，文字、额度圆圈、按钮保持清晰；继续使用 macOS 原生弹出与收起动画。
- 磨砂强度控制系统材质的混合程度，不使用私有模糊半径接口。系统外观、辅助功能和背景仍会影响最终显示。

推荐安装 `CodexMeter-1.5.1.8-universal.pkg` 自动替换旧版，保留设置与登录。支持 macOS 13+、Apple 芯片与 Intel；DMG / ZIP 为手动替换。

Windows 继续使用 [1.5.2](https://github.com/Haofei-Hu/codex-meter/releases/tag/v1.5.2)，Linux 继续使用 [1.5.1](https://github.com/Haofei-Hu/codex-meter/releases/tag/v1.5.1)。MIT · Independent project, not affiliated with OpenAI.
